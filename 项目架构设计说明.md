### 架构特点

1. **分层架构**: 清晰的层次分离，便于维护和扩展
2. **微服务思维**: 模块化设计，支持独立部署和扩展
3. **异步处理**: 充分利用FastAPI的异步特性，提升并发性能
4. **依赖注入**: 使用依赖注入容器，解耦组件依赖
5. **统一接口**: RESTful API设计，标准化的接口规范

## 技术架构

### 核心技术栈

#### 1. Web框架
- **FastAPI**: 现代化的异步Web框架
  - 基于Starlette和Pydantic
  - 自动API文档生成
  - 类型提示和数据验证
  - 异步请求处理

#### 2. 数据库技术
- **SQLAlchemy**: Python ORM框架
  - 支持异步操作
  - 强大的查询构建器
  - 数据库迁移支持(Alembic)
- **MySQL 8.0**: 主数据库
  - ACID事务支持
  - 高效的索引和查询
  - JSON字段支持
- **Redis**: 缓存和会话存储
  - 高性能键值存储
  - 支持数据结构丰富
  - 发布订阅模式

#### 3. AI服务集成
- **DeepSeek AI**: 主要AI服务提供商
- **Alibaba AI**: 备用AI服务提供商
- **负载均衡器**: 智能选择最优AI服务
- **故障转移**: 自动切换到可用服务

#### 4. 安全技术
- **JWT认证**: 无状态身份验证
- **bcrypt密码哈希**: 安全密码存储
- **CORS**: 跨域资源共享
- **输入验证**: Pydantic数据验证
- **SQL注入防护**: ORM参数化查询

## 数据库设计

### 数据库架构

```sql
-- 数据库：llm_chat
-- 字符集：utf8mb4
-- 排序规则：utf8mb4_unicode_ci

-- 用户表
CREATE TABLE user (
    id INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(100) UNIQUE NOT NULL,
    username VARCHAR(100) NOT NULL,
    _password VARCHAR(200) NOT NULL,
    nickname VARCHAR(100) DEFAULT '',
    gender VARCHAR(10) DEFAULT '未知',
    avatar TEXT DEFAULT '',
    phone VARCHAR(11) DEFAULT '' UNIQUE,
    INDEX idx_email (email),
    INDEX idx_phone (phone)
);

-- 邮箱验证码表
CREATE TABLE email_code (
    id INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(100) NOT NULL,
    code VARCHAR(10) NOT NULL,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 姓名生成历史记录表
CREATE TABLE name_history (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    input_params JSON NOT NULL,
    generated_names JSON NOT NULL,
    model_used VARCHAR(50) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
);

-- 姓名收藏表
CREATE TABLE name_favorite (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    history_id INT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE CASCADE,
    FOREIGN KEY (history_id) REFERENCES name_history(id) ON DELETE CASCADE,
    UNIQUE KEY uq_user_history (user_id, history_id)
);

-- 企业起名历史记录表
CREATE TABLE company_name_history (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    industry VARCHAR(100) NOT NULL,
    company_type VARCHAR(50) NOT NULL,
    business_scope TEXT NOT NULL,
    positioning VARCHAR(200),
    length VARCHAR(20) NOT NULL,
    style VARCHAR(50),
    exclude JSON DEFAULT ('[]'),
    generated_names JSON NOT NULL,
    model_used VARCHAR(50) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
);

-- 企业起名收藏表
CREATE TABLE company_name_favorite (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    history_id INT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE CASCADE,
    FOREIGN KEY (history_id) REFERENCES company_name_history(id) ON DELETE CASCADE,
    UNIQUE KEY uq_user_history (user_id, history_id)
);

-- 产品起名历史记录表
CREATE TABLE product_name_history (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    product_type VARCHAR(100) NOT NULL,
    product_function TEXT NOT NULL,
    target_audience VARCHAR(100),
    market_positioning VARCHAR(100),
    length VARCHAR(20) NOT NULL,
    style VARCHAR(50),
    exclude JSON DEFAULT ('[]'),
    generated_names JSON NOT NULL,
    model_used VARCHAR(50) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
);

-- 产品起名收藏表
CREATE TABLE product_name_favorite (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    history_id INT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE CASCADE,
    FOREIGN KEY (history_id) REFERENCES product_name_history(id) ON DELETE CASCADE,
    UNIQUE KEY uq_user_history (user_id, history_id)
);

-- 使用统计表
CREATE TABLE usage_stats (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    action_type VARCHAR(50) NOT NULL,
    action_data JSON,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id),
    INDEX idx_user_action (user_id, action_type),
    INDEX idx_created_at (created_at)
);

-- 姓名重复度统计表
CREATE TABLE name_repetition (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    gender VARCHAR(10) NOT NULL,
    region VARCHAR(50) DEFAULT '全国',
    count INT DEFAULT 1,
    last_updated DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uq_name_gender_region (name, gender, region),
    INDEX idx_gender_region (gender, region),
    INDEX idx_count (count DESC)
);
```

### 数据库设计原则

1. **规范化设计**: 遵循第三范式，减少数据冗余
2. **索引优化**: 为常用查询字段添加适当索引
3. **外键约束**: 维护数据完整性
4. **JSON字段**: 灵活存储复杂数据结构
5. **时间戳**: 记录重要操作的时间
6. **唯一约束**: 防止重复数据

## API设计

### RESTful API设计原则

1. **资源导向**: 以资源为中心设计URL
2. **HTTP方法**: 使用标准HTTP方法表达操作意图
3. **状态码**: 使用标准HTTP状态码
4. **版本控制**: 通过URL路径进行API版本管理
5. **一致性**: 统一的请求/响应格式

### API版本控制

```
当前版本: v1
基础路径: /api/v1

版本管理策略:
- URL路径版本: /api/v1/*
- 向后兼容: 新版本API不影响旧版本
- 废弃策略: 标记废弃但保持可用
```

### 接口规范

#### 请求格式
```http
POST /api/v1/name HTTP/1.1
Content-Type: application/json
Authorization: Bearer <access_token>

{
  "surname": "张",
  "gender": "男",
  "length": "两字"
}
```

#### 响应格式
```http
HTTP/1.1 200 OK
Content-Type: application/json

{
  "names": [
    {
      "name": "张文博",
      "reason": "有文化底蕴"
    }
  ]
```

## 安全设计

### 认证与授权

#### JWT认证流程
1. 用户登录获取访问令牌和刷新令牌
2. 客户端在请求头中携带访问令牌
3. 服务器验证令牌有效性和权限
4. 令牌过期时使用刷新令牌获取新令牌

#### 密码安全
- bcrypt哈希算法保护密码
- 密码复杂度要求（最少8位）
- 防止暴力破解的延迟机制

### 数据安全

#### 输入验证
- Pydantic自动数据验证
- SQL注入防护（ORM参数化查询）
- XSS防护（输入清理）

#### 文件上传安全
- 文件类型限制（仅图片）
- 文件大小限制（最大5MB）
- 安全的文件名生成（UUID）

### API安全

#### 频率限制
```python
# 实现频率限制
from slowapi import Limiter

limiter = Limiter(key_func=get_remote_address)

@app.post("/auth/login")
@limiter.limit("5/minute")

    pass
```

#### CORS配置

```python
# 跨域资源共享
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
```

- **性能监控**: 响应时间、错误率、并发数

#### 日志管理
- **结构化日志**: JSON格式日志
- **日志级别**: DEBUG、INFO、WARNING、ERROR
- **日志轮转**: 按大小和时间轮转
- **集中日志**: 可选ELK Stack

- **全量备份**: 每日凌晨2点
- **增量备份**: 每4小时一次
- **备份保留**: 7天本地，30天云存储

#### 文件备份
- **头像文件**: 随数据库备份
- **配置文件**: 版本控制管理

## 总结

本项目采用现代化的技术栈和架构设计，具有以下优势：

1. **高性能**: 异步处理、连接池、缓存优化
2. **高可用**: 负载均衡、故障转移、健康检查
3. **高安全**: JWT认证、数据验证、访问控制
4. **易维护**: 分层架构、依赖注入、统一规范
5. **易扩展**: 模块化设计、微服务思维、标准化接口

该架构设计既满足当前业务需求，又为未来发展预留了充分空间，是一个成熟的企业级应用架构。
